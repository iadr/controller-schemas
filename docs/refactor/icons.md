# Iconografia

Los iconos se importan por nombre desde react-icons/bs y react-icons/fa.
Pantalla y PNG comparten SVG inline; index.html no carga fuentes de iconos externas.
Las etiquetas bi bi-* y fas/fa/far fa-* de los JSON existentes se resuelven mediante un adaptador.
No se cambian las claves label:* persistidas.

Referencia: https://react-icons.github.io/react-icons/
